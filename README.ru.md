# 🪝 Claw

[English](README.md) · [Español](README.es.md) · [Català](README.ca.md) · [Français](README.fr.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · **Русский** · [العربية](README.ar.md) · [中文](README.zh.md)

**Самостоятельно размещаемый бот WhatsApp с локальным ИИ.**

Claw — это ассистент WhatsApp с локальным ИИ, который следит за домашними заданиями, контрольными, объявлениями из школы и важной информацией из групповых чатов.

Он тихо работает в фоне, понимает текстовые сообщения, голосовые заметки и нужные изображения и отвечает на вопросы, когда кому-то нужна информация.

> **Установка:** см. [INSTALL.ru.md](INSTALL.ru.md) с подробными инструкциями для Linux, macOS и Windows.
>
> **Техническая документация:** [Архитектура, API и безопасность](docs/arquitectura.md).

## ✨ Возможности

- **Автоматический учёт домашних заданий:** распознаёт и записывает задания и предстоящие контрольные из переписки в группе.
- **Тихая работа:** Claw говорит только когда его спрашивают или явно активируют.
- **Универсальный ИИ-ассистент:** упомяните `Claw` и задайте вопрос, чтобы использовать общие возможности ИИ.
- **Распознавание речи:** расшифровывает голосовые сообщения локально с помощью Whisper.
- **Хранение изображений:** сохраняет изображения, связанные с заданиями и контрольными, и автоматически удаляет устаревшие файлы.
- **Локальная обработка ИИ:** использует Ollama для запуска языковых моделей на вашем компьютере.
- **Выбор языка при первом запуске:** при первом старте Claw открывает веб-страницу для выбора одного из 100 языков. Выбор сохраняется в базе данных, применяется к интерфейсу и ответам ИИ и может быть изменён позже командой `!claw language en`.
- **Веб-интерфейс:** даёт ученикам авторизованный доступ к общей школьной информации.
- **Интеграция с календарём:** экспортирует предстоящие контрольные в файлы `.ics`.
- **Шахматы:** играйте в шахматы против Claw или анализируйте позиции.
- **Необязательная генерация изображений:** локально с Stable Diffusion.
- **Автоматическое обслуживание:** управляет сохранёнными файлами и может не давать компьютеру уходить в сон.

### 🔒 Конфиденциальность

Claw построен вокруг локальной обработки.

Вывод ИИ, классификация и база данных работают на вашем компьютере.

Некоторые внешние соединения всё же нужны:

- WhatsApp: доставка и получение сообщений.
- Ollama и Whisper: загрузка моделей.
- DuckDuckGo: необязательный поиск в интернете.

Поиск можно отключить через `WEB_SEARCH=false` или `!claw ajustes buscar no`.

Подробнее в [документации о конфиденциальности](docs/arquitectura.md#datos-y-privacidad).

## 🧠 Как это работает

Claw анализирует входящие сообщения группы и решает, что делать.

```text
Входящее сообщение из группы
        |
        +-- Содержит "Claw"?
        |       |
        |       +-- Универсальный ИИ-ассистент
        |
        +-- Это вопрос о заданиях или контрольных?
        |       |
        |       +-- Отвечает напрямую из базы данных
        |
        +-- Может содержать школьную информацию?
                |
                +-- Классификация локальным ИИ
                        |
                        +-- Обнаружен вопрос
                        |       |
                        |       +-- Открывает открытый вопрос на 15 минут
                        |
                        +-- Обнаружена информация
                                |
                                +-- Тихо сохраняет в базу данных
```

### Открытые вопросы

Одна из главных функций Claw — система открытых вопросов.

Например:

1. Ученик спрашивает: «Какое домашнее задание по английскому?»
2. Claw открывает вопрос на 15 минут.
3. Другой ученик отвечает: «Сделать страницу 12».
4. Claw автоматически сохраняет информацию.
5. Любой может позже спросить Claw о задании по английскому.

Исправления заменяют предыдущие записи, поэтому устаревшая информация не остаётся в базе.

Claw также понимает контекст разговора по последним сообщениям того же чата, не смешивая разные беседы.

### 🎙️ Голосовые сообщения

Claw понимает голосовые сообщения с помощью Whisper.

- Аудио расшифровывается локально.
- Служба Python использует faster-whisper.
- Есть запасной вариант на Node.js.
- Распознаёт другие произношения имени, например «Clau» и «Clao».
- Аудио никогда не покидает ваш компьютер для расшифровки.

### 🖼️ Изображения

Claw может сохранять изображения, связанные с заданиями и контрольными.

- Нужные школьные изображения сохраняются.
- Мемы и посторонние изображения игнорируются.
- Устаревшие файлы удаляются автоматически.
- Изображения можно отправить снова, когда кто-то спрашивает о контрольной.

## 🚀 Установка

Полные инструкции — в **[INSTALL.ru.md](INSTALL.ru.md)**.

### Требования

| Зависимость       | Версия / модель                        |
| ----------------- | -------------------------------------- |
| Node.js           | 24 LTS                                 |
| Git               | Последняя версия                       |
| Ollama            | Последняя версия                       |
| Основная модель   | `qwen3:4b`                             |
| Резервная модель  | `qwen2.5:3b`                           |
| Python            | 3.11 / 3.12 (рекомендуется)            |
| FFmpeg            | Необязательно, для старого режима речи |

Загрузите модели:

```bash
ollama pull qwen3:4b
ollama pull qwen2.5:3b
```

### Клонирование репозитория

```bash
git clone <REPOSITORY_URL>
cd Claw
```

Установите зависимости:

```bash
npm install
```

В Windows можно также запустить:

```powershell
.\arrancar.bat
```

Этот скрипт устанавливает недостающие зависимости, создаёт конфигурацию окружения и запускает бота.

### Необязательная служба Python

Служба Python улучшает обработку речи и позволяет генерировать изображения локально.

Создайте виртуальное окружение:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r python/requirements.txt
pip install -r python/requirements-images.txt
```

Запустите службу:

```bash
python python/server.py
```

Проверьте состояние:

```bash
curl http://127.0.0.1:5050/health
```

Подробнее в [python/README.md](python/README.md).

## 📱 Подключение WhatsApp

Запустите Claw:

```bash
npm start
```

Отсканируйте QR-код в:

**WhatsApp → Настройки → Связанные устройства → Привязка устройства**

Сессия авторизации сохраняется в:

```text
data/auth/
```

**Никогда не передавайте эту папку и её содержимое.**

### Активация Claw в группе

Есть два способа подключить группу:

**Вручную:**

```text
!claw aqui
```

**Автоматически:**

Укажите внутренний идентификатор группы в `.env`:

```env
WHATSAPP_GROUP_JID=your-group-id@g.us
```

Claw определяет группы по внутреннему идентификатору, а не по названию.

## 🌐 Веб-интерфейс

Claw включает веб-интерфейс и API.

Запустить только веб-сервер:

```bash
npm run web
```

Запустить всё:

```bash
npm start
```

Веб-интерфейс обслуживает сам сервер Claw:

- `/` — Главная страница.
- `/entrar/` — Вход для учеников.

### Авторизация учеников

Для входа нужен одноразовый код подтверждения по электронной почте.

Текущие правила:

- Принимаются только адреса `@alu.edu.gva.es`.
- Ученики указывают имя, фамилию, курс и группу.
- Коды действуют 10 минут.
- Не более пяти попыток подтверждения.
- Сессии истекают через восемь часов или при перезапуске сервера.
- Авторизованные ученики видят одни и те же записи о заданиях и контрольных.

### Доступ из сети

Claw сам отдаёт веб-страницу по адресу `http://127.0.0.1:3000`, поэтому туннель не нужен. Если вы публикуете её на другом домене (например, за HTTPS-обратным прокси), добавьте его в `WEB_ALLOWED_ORIGINS` через запятую.

Для подтверждения по почте нужны данные SMTP.

**Предупреждение о безопасности:** функцию отладочного доступа нужно настраивать осторожно. Никогда не оставляйте отладочный код по умолчанию на сервере, доступном из интернета.

См. [документацию по архитектуре и безопасности](docs/arquitectura.md).

## 🎨 Локальная генерация изображений (эксперимент)

Claw может генерировать изображения локально.

Доступные движки:

- **Python + Diffusers:** множество моделей через Hugging Face.
- **stable-diffusion.cpp:** лёгкая генерация из командной строки.
- **HTTP-бэкенд:** совместимые серверы генерации изображений.

По умолчанию генерация отключена.

Включите:

```text
!claw ajustes imagenes si
```

Сгенерируйте изображение:

```text
!claw imagen a futuristic city at night
```

Claw никогда не генерирует изображения автоматически.

На системах с малым объёмом памяти GPU генерация может временно выгрузить модель Ollama, чтобы освободить VRAM.

## ❓ Вопросы и ответы

**Нужен ли Claw интернет?**

WhatsApp и необязательные внешние сервисы требуют соединения. Локальный вывод ИИ и база данных работают на вашем компьютере.

**Можно ли пользоваться Claw при выключенном телефоне?**

Да, если компьютер остаётся включённым, а сессия связанного устройства WhatsApp действительна.

**Что будет, если компьютер выключится?**

Claw перестанет работать, но информация останется в `data/picklebrain.db`.

**Может ли WhatsApp заблокировать мой номер?**

Риск реальный. Claw использует Baileys — неофициальную библиотеку WhatsApp Web. Условия WhatsApp ограничивают несанкционированную автоматизацию. Рекомендуется отдельный номер.

**Claw сильно нагружает компьютер?**

Зависит от моделей и железа. Обычные вопросы отвечаются прямо из базы, без запуска модели.

**Сохраняются ли все изображения?**

Нет. По умолчанию только нужные школьные изображения, а старые файлы удаляются автоматически.

**Почему Claw не отвечает?**

1. Проверьте, что группа подключена.
2. Введите `!claw` для статуса.
3. Запустите `npm run doctor`.
4. Включите `LOG_LEVEL=debug`, чтобы видеть обработку сообщений.

**Почему не работает распознавание речи?**

Проверьте, что служба Python запущена, или установите FFmpeg для старого движка расшифровки на Node.js.

## ⚠️ Ограничения и планы

- APK-компаньон для Android не входит в репозиторий. API ожидает вложение последнего релиза с именем `ClawCompanion.apk`.
- Большие языковые модели улучшают беседу при достаточном железе.
- Большие модели Whisper лучше распознают имена и шумные записи.
- Генерация изображений экспериментальна и зависит от железа и совместимости моделей.
