Claw مساعد على واتساب يعمل بذكاء اصطناعي محلي، ويتابع الواجبات والامتحانات وإعلانات المدرسة والمعلومات المهمة التي تُشارَك في مجموعات المحادثة.

يعمل بهدوء في الخلفية، ويفهم الرسائل النصية والرسائل الصوتية والصور ذات الصلة، ويجيب على الأسئلة عندما يحتاج أحد إلى معلومة.

> **التثبيت:** راجع [INSTALL.ar.md](INSTALL.ar.md) للحصول على خطوات مفصّلة في Linux وmacOS وWindows.
>
> **التوثيق التقني:** [البنية وواجهة API والأمان](docs/arquitectura.md).

## ✨ الميزات

- **تتبّع تلقائي للواجبات:** يتعرّف على الواجبات والامتحانات القادمة من محادثات المجموعة ويسجّلها.
- **عمل صامت:** لا يتحدث Claw إلا عندما يُسأل أو يُستدعى صراحةً.
- **مساعد ذكاء اصطناعي عام:** اكتب `Claw` متبوعًا بسؤال لاستخدام قدراته العامة.
- **التعرّف على الكلام:** يفرّغ الرسائل الصوتية محليًا باستخدام Whisper.
- **تخزين الصور:** يحفظ الصور المرتبطة بالواجبات والامتحانات ويحذف الملفات المنتهية تلقائيًا.
- **معالجة محلية للذكاء الاصطناعي:** يستخدم Ollama لتشغيل نماذج اللغة على جهازك.
- **اختيار اللغة عند أول تشغيل:** عند أول تشغيل يفتح Claw صفحة ويب للاختيار من 100 لغة. يُحفظ الاختيار في قاعدة البيانات ويُطبَّق على الواجهة وعلى ردود الذكاء الاصطناعي، ويمكن تغييره لاحقًا بالأمر `!claw language en`.
- **واجهة ويب:** تمنح الطلاب وصولًا مُصادَقًا إلى المعلومات المدرسية المشتركة.
- **تكامل مع التقويم:** يصدّر الامتحانات القادمة كملفات `.ics`.
- **الشطرنج:** العب الشطرنج ضد Claw أو حلّل الأوضاع.
- **توليد صور اختياري:** يولّد الصور محليًا باستخدام Stable Diffusion.
- **صيانة تلقائية:** يدير الوسائط المحفوظة ويمكنه منع جهاز الاستضافة من الدخول في وضع السكون.

### 🔒 الخصوصية

صُمّم Claw حول المعالجة المحلية.

استدلال الذكاء الاصطناعي والتصنيف وقاعدة البيانات تعمل على جهازك.

لكن تبقى بعض الاتصالات الخارجية ضرورية:

- واتساب: إرسال الرسائل واستقبالها.
- Ollama وWhisper: تنزيل النماذج.
- DuckDuckGo: بحث اختياري في الويب.

يمكن تعطيل البحث في الويب عبر `WEB_SEARCH=false` أو `!claw ajustes buscar no`.

راجع [وثيقة الخصوصية](docs/arquitectura.md#datos-y-privacidad) لمزيد من التفاصيل.

## 🧠 كيف يعمل

يحلّل Claw الرسائل الواردة في المجموعة ويقرّر ما يجب فعله.

```text
رسالة واردة من المجموعة
        |
        +-- هل تحتوي على "Claw"؟
        |       |
        |       +-- مساعد ذكاء اصطناعي عام
        |
        +-- هل هي سؤال عن واجب أو امتحان؟
        |       |
        |       +-- يجيب مباشرة من قاعدة البيانات
        |
        +-- هل قد تحتوي على معلومات مدرسية؟
                |
                +-- تصنيف بواسطة الذكاء الاصطناعي المحلي
                        |
                        +-- تم رصد سؤال
                        |       |
                        |       +-- يفتح سؤالًا معلّقًا لمدة 15 دقيقة
                        |
                        +-- تم رصد معلومة
                                |
                                +-- يحفظها بصمت في قاعدة البيانات
```

### الأسئلة المعلّقة

من أهم وظائف Claw نظام الأسئلة المعلّقة.

مثال:

1. يسأل طالب: «ما واجب اللغة الإنجليزية؟»
2. يفتح Claw سؤالًا معلّقًا لمدة 15 دقيقة.
3. يجيب زميل: «اعملوا الصفحة 12.»
4. يحفظ Claw المعلومة تلقائيًا.
5. يمكن لأي شخص أن يسأل Claw لاحقًا عن واجب الإنجليزية.

التصحيحات تستبدل السجلات السابقة، لذا لا تبقى المعلومات القديمة في قاعدة البيانات.

يفهم Claw أيضًا سياق المحادثة من الرسائل الأخيرة في المحادثة نفسها، دون خلط المحادثات المختلفة.

### 🎙️ الرسائل الصوتية

يفهم Claw الرسائل الصوتية باستخدام Whisper.

- يُفرَّغ الصوت محليًا.
- تستخدم خدمة Python مكتبة faster-whisper.
- يوجد بديل بلغة Node.js.
- يتعرّف على نطق الاسم بطرق أخرى مثل «Clau» و«Clao».
- لا يحتاج الصوت إلى مغادرة جهازك ليُفرَّغ.

### 🖼️ الصور

يمكن لـ Claw حفظ الصور المرتبطة بالواجبات والامتحانات.

- تُحفظ الصور المدرسية ذات الصلة.
- تُتجاهل الصور غير المناسبة والميمز.
- تُحذف الوسائط المنتهية تلقائيًا.
- يمكن إعادة إرسال الصور عندما يسأل أحد عن امتحان.

## 🚀 التثبيت

للخطوات الكاملة راجع **[INSTALL.ar.md](INSTALL.ar.md)**.

### المتطلبات

| المتطلب        | الإصدار / النموذج                    |
| -------------- | ------------------------------------ |
| Node.js        | 24 LTS                               |
| Git            | أحدث إصدار                           |
| Ollama         | أحدث إصدار                           |
| النموذج الأساسي| `qwen3:4b`                           |
| النموذج البديل | `qwen2.5:3b`                         |
| Python         | 3.11 / 3.12 (مُستحسن)                |
| FFmpeg         | اختياري، للصوت في الوضع القديم       |

نزّل النماذج:

```bash
ollama pull qwen3:4b
ollama pull qwen2.5:3b
```

### استنساخ المستودع

```bash
git clone <REPOSITORY_URL>
cd Claw
```

ثبّت التبعيات:

```bash
npm install
```

ويمكنك في Windows أيضًا تشغيل:

```powershell
.\arrancar.bat
```

يثبّت هذا السكربت التبعيات الناقصة، ويُنشئ إعداد البيئة، ويشغّل البوت.

### خدمة Python الاختيارية

تحسّن خدمة Python معالجة الصوت وتتيح توليد الصور محليًا.

أنشئ بيئة افتراضية:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

ثبّت التبعيات:

```bash
pip install -r python/requirements.txt
pip install -r python/requirements-images.txt
```

شغّل الخدمة:

```bash
python python/server.py
```

تحقّق من الحالة:

```bash
curl http://127.0.0.1:5050/health
```

راجع [python/README.md](python/README.md) لمزيد من التفاصيل.

## 📱 ربط واتساب

شغّل Claw:

```bash
npm start
```

امسح رمز QR في:

**واتساب → الإعدادات → الأجهزة المرتبطة → ربط جهاز**

تُحفظ جلسة الدخول في:

```text
data/auth/
```

**لا تشارك هذا المجلد ولا محتواه أبدًا.**

### تفعيل Claw في مجموعة

هناك طريقتان لربط مجموعة:

**يدويًا:**

```text
!claw aqui
```

**تلقائيًا:**

اكتب معرّف المجموعة الداخلي في `.env`:

```env
WHATSAPP_GROUP_JID=your-group-id@g.us
```

يتعرّف Claw على المجموعات بمعرّفها الداخلي، لا باسمها.

## 🌐 واجهة الويب

يتضمّن Claw واجهة ويب وواجهة API مدمجتين.

تشغيل خادم الويب فقط:

```bash
npm run web
```

تشغيل كل شيء:

```bash
npm start
```

تخدم واجهة الويب من خادم Claw نفسه:

- `/` — الصفحة الرئيسية.
- `/entrar/` — دخول الطلاب.

### مصادقة الطلاب

يتطلب الدخول رمز تحقق لمرة واحدة يُرسل بالبريد الإلكتروني.

القواعد الحالية:

- تُقبل عناوين `@alu.edu.gva.es` فقط.
- يسجّل الطلاب الاسم واللقب والصف والمجموعة.
- تنتهي صلاحية الرموز بعد 10 دقائق.
- خمس محاولات تحقق كحد أقصى.
- تنتهي الجلسات بعد ثماني ساعات أو عند إعادة تشغيل الخادم.
- يرى الطلاب المسجّلون سجلات الواجبات والامتحانات نفسها.

### الوصول من الشبكة

يخدم Claw صفحة الويب بنفسه على `http://127.0.0.1:3000`، لذا لا حاجة إلى أي نفق. وإذا نشرتها على نطاق آخر (خادم وكيل عكسي مع HTTPS مثلًا)، فأضفه إلى `WEB_ALLOWED_ORIGINS` مفصولًا بفواصل.

يحتاج التحقق بالبريد إلى بيانات SMTP.

**تنبيه أمني:** يجب إعداد وظيفة دخول التصحيح بعناية. لا تترك أبدًا رمز تصحيح افتراضيًا على خادم متاح من الإنترنت.

راجع [وثيقة البنية والأمان](docs/arquitectura.md).

## 🎨 توليد الصور محليًا (تجريبي)

يدعم Claw اختياريًا توليد الصور محليًا.

المحرّكات المتاحة:

- **Python + Diffusers:** نماذج كثيرة عبر Hugging Face.
- **stable-diffusion.cpp:** توليد خفيف من سطر الأوامر.
- **خادم HTTP:** خوادم توليد صور متوافقة.

توليد الصور معطّل افتراضيًا.

لتفعيله:

```text
!claw ajustes imagenes si
```

لتوليد صورة:

```text
!claw imagen a futuristic city at night
```

لا يولّد Claw الصور تلقائيًا أبدًا.

على الأنظمة ذات ذاكرة GPU الصغيرة قد يُفرّغ التوليد نموذج Ollama مؤقتًا لتحرير VRAM.

**هل يحتاج Claw إلى اتصال بالإنترنت؟**

يحتاج واتساب والخدمات الخارجية الاختيارية إلى اتصال. أما استدلال الذكاء الاصطناعي المحلي وقاعدة البيانات فيعملان على جهازك.

**هل يمكنني استخدام Claw والهاتف مغلق؟**

نعم، ما دام جهاز الاستضافة يعمل وجلسة الجهاز المرتبط في واتساب صالحة.

**ماذا يحدث إذا أُغلق الجهاز؟**

يتوقف Claw، لكن المعلومات المحفوظة تبقى في `data/picklebrain.db`.

**هل يمكن أن يحظر واتساب رقمي؟**

الخطر حقيقي. يستخدم Claw مكتبة Baileys، وهي مكتبة WhatsApp Web غير رسمية. وشروط واتساب تحدّ من الأتمتة غير المصرّح بها. يُنصح باستخدام رقم منفصل.

**هل يستهلك Claw موارد كثيرة؟**

يعتمد ذلك على النماذج والعتاد. الأسئلة المعتادة تُجاب مباشرة من قاعدة البيانات دون تشغيل نموذج.

**هل تُحفظ كل الصور؟**

لا. افتراضيًا تُحفظ الصور المدرسية ذات الصلة فقط، وتُحذف الملفات القديمة تلقائيًا.

**لماذا لا يجيب Claw؟**

1. تحقّق من أن المجموعة مرتبطة.
2. اكتب `!claw` لمعرفة الحالة.
3. شغّل `npm run doctor`.
4. فعّل `LOG_LEVEL=debug` لترى كيف تُعالَج الرسائل.

**لماذا لا يعمل التعرّف على الكلام؟**

تحقّق من أن خدمة Python تعمل، أو ثبّت FFmpeg لمحرّك التفريغ القديم في Node.js.

- تطبيق Android المرافق غير موجود في هذا المستودع. تتوقع واجهة API أن يكون مرفق آخر إصدار باسم `ClawCompanion.apk`.

- نماذج Whisper الأكبر تحسّن التعرّف على الأسماء والتسجيلات المزعجة.
- توليد الصور تجريبي ويعتمد على العتاد وتوافق النماذج.
